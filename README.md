# Personal Portfolio Template

A minimal, modern, and responsive developer portfolio built with Next.js 15, React 19, Tailwind CSS v4, and Motion.

Designed to help developers showcase their projects, technical skills, professional experience, and personal brand through a clean and interactive interface.

Feel free to clone, customize, and use this template for your own portfolio.

## Features

- Minimal and responsive one-page layout.
- Interactive project showcase with image and video previews.
- Technology stack section with icons and hover animations.
- Work experience and professional background.
- Light and dark theme support.
- Smooth animations and transitions.
- Social media and contact links.
- MDX blog support.
- Easy customization.

## Tech Stack

- **Framework:** Next.js 15
- **Library:** React 19
- **Styling:** Tailwind CSS v4
- **Animations:** Motion
- **Language:** TypeScript
- **Content:** MDX

## Getting Started

### Prerequisites

- Node.js
- npm
- Git

### 1. Clone the repository

```bash
git clone https://github.com/Omkkar27/portfolio.git
```

### 2. Navigate to the project directory

```bash
cd portfolio
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000) to view your portfolio.

## Customization

Personalize the template by editing these files:

| File             | Purpose                                               |
| ---------------- | ----------------------------------------------------- |
| `app/data.ts`    | Projects, experience, skills, social links, and email |
| `app/page.tsx`   | Main portfolio layout                                 |
| `app/layout.tsx` | Metadata and SEO settings                             |
| `public/`        | Images, icons, and project previews                   |
| `components/ui/` | Reusable UI components                                |

Update the content, add your own projects, replace images, and customize the design to make it yours.

## Deployment

Deploy your portfolio easily using [Vercel](https://vercel.com/).

1. Push your customized repository to GitHub.
2. Import the repository into Vercel.
3. Configure environment variables if required.
4. Deploy your application.
